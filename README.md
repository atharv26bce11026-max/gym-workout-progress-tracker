# Gym Workout Tracker

## About the Project

Gym Workout Tracker is a simple Python project made to keep track of gym workouts.

Instead of writing down exercises, sets, reps and weights somewhere else, the user can enter them directly into the application. The project also shows the saved workout history and calculates some basic workout statistics.

I made this project as a beginner-level Python project to practice basic Python programming along with a simple graphical user interface.

## Features

* Add a new workout
* Enter exercise name, sets, reps and weight
* View workout history
* Calculate total training volume
* Basic input validation
* Simple and easy-to-use GUI
* Exit option to close the application

## Technologies Used

* Python
* Tkinter

Tkinter is used to create the graphical user interface. No external Python libraries are required.

## How to Run

### 1. Install Python

Make sure Python is installed on your computer.

You can check it by running:

```bash
python --version
```

### 2. Download the Project

Clone this repository or download the project files.

```bash
git clone <your-github-repository-link>
```

### 3. Open the Project Folder

Open the project folder in VS Code, PyCharm, or any Python-supported editor.

### 4. Run the Program

Run the following command:

```bash
python main.py
```

The Gym Workout Tracker window will open.

## How to Use

1. Enter the exercise name.
2. Enter the number of sets.
3. Enter the number of reps.
4. Enter the weight in kilograms.
5. Click **Add Workout**.
6. The workout will appear in the workout history.
7. Click **Show Statistics** to see the total number of workouts and total training volume.

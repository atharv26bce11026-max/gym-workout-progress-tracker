# Project Statement

## Project Title

**Gym Workout Tracker**

## Problem Statement

Many people who go to the gym find it difficult to keep track of their workouts regularly. They may forget the weights, sets, or repetitions they used in their previous workouts.

The Gym Workout Tracker is a simple application that helps users record their workout details in one place. It allows users to enter exercises, sets, repetitions, and weights and then view their workout history.

The project is designed to make basic workout tracking easier while also providing simple statistics about the user's training.

## Project Scope

The main purpose of this project is to provide a simple way to record and review gym workouts.

The project currently focuses on:

* Recording workout details
* Storing workout information while the program is running
* Viewing previous workouts
* Calculating basic workout statistics
* Providing a simple graphical interface

The project is kept simple so that it can be easily used and understood by beginners.

## Target Users

The main target users are:

* Gym beginners
* Students who go to the gym
* People who want to keep a simple record of their workouts

## High-Level Features

### 1. Add Workout

Users can enter:

* Exercise name
* Number of sets
* Number of repetitions
* Weight used

### 2. Workout History

Users can view the workouts they have added during the current session.

### 3. Workout Statistics

The application calculates:

* Total number of workouts
* Total training volume

### 4. Input Validation

The application checks for:

* Empty fields
* Invalid numerical values
* Invalid sets, reps, or weight values

### 5. Simple GUI

The project uses Python's Tkinter library to provide a basic graphical interface that is easy to use.

## Project Objective

The objective of this project is to apply basic Python programming concepts such as variables, lists, dictionaries, functions, loops, conditional statements, exception handling, and GUI programming to solve a simple real-world problem.
